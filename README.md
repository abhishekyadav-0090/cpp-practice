# C++ Practice and DSA

A structured collection of my C++ learning exercises and data-structures-and-algorithms practice.

## Topics

- `01-patterns` — loops and console patterns
- `02-arrays` — static arrays, vectors, and array operations
- `03-pointers` — pointers, references, dynamic memory, and structs
- `04-vectors` — vector-based algorithm problems
- `05-matrices` — 2D vectors and matrix algorithms

## Build and run

Every example is a standalone program. Compile one file at a time:

```powershell
g++ -std=c++17 -Wall -Wextra -Wpedantic 04-vectors/two_sum.cpp -o two_sum
.\two_sum.exe
```

## Conventions

- File names describe the concept or problem.
- Each algorithm keeps its implementation in one source file with a small example in `main`.
- Compiled files are intentionally ignored by Git.

See [the problem index](problems.md) for selected examples and their complexity.
